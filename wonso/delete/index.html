원소술사 키우기 계정 삭제 안내

원소술사 키우기는 게임 기록을 지키기 위해 서버에 계정과 게임 데이터를 보관해요. 언제든지 계정과 데이터를 삭제할 수 있어요.

1. 게임 안에서 삭제하기 (바로 처리)

  1. 게임을 켜고 [메뉴] → 설정을 눌러요.
  2. 설정 창 맨 아래의 계정 삭제를 눌러요.
  3. 안내를 읽고 삭제하기 → 영구 삭제를 눌러요.
  4. 인터넷에 연결되어 있어야 해요. 삭제가 끝나면 게임이 처음 화면부터 새로 시작해요.

2. 게임 없이 요청하기 (게임을 지웠을 때)

kiblogames.official@gmail.com 으로 아래 내용을 보내 주세요.

  • 제목: 계정 삭제 요청
  • 게임 안에서 쓰던 닉네임(마법사 이름)
  • 이름을 정하지 않았다면 마지막으로 플레이한 날짜와 최고 스테이지

요청을 받은 날부터 7일 안에 삭제하고 메일로 알려 드려요. 본인 확인이 어려우면 몇 가지를 더 여쭤볼 수 있어요.

삭제되는 정보

  • 게임 기록(층 · 장비 · 소환수 · 마법 · 유물 · 도감 등)과 서버에 보관된 저장 사본
  • 보석 · 별의 조각 · 뽑기권 등 재화와 구매 기록(월정액 · 패키지 · 광고 제거 포함)
  • 닉네임, 친구 초대 코드와 초대 기록
  • 이번 주 순위에 올라간 닉네임과 층 — 삭제하면 바로 순위에서 빠지고 닉네임도 지워져요. 지난주 순위 보관함에는 닉네임 없이 무작위 계정 번호와 층만 남아요(보상 계산용 — 계정이 지워진 뒤에는 누구의 것인지 알 수 없어요)
  • 로그인 계정(게임이 자동으로 만든 익명 계정)과 구글 플레이 게임즈 계정과의 묶음(구글 로그인을 했다면 — 지운 뒤 같은 구글 계정으로 로그인하면 새 게임으로 시작해요)

삭제되지 않거나 따로 보관되는 정보

  • 결제 내역: 결제는 구글 플레이가 처리해요. 구글 계정의 주문 내역은 구글이 법에 따라 보관하며, 게임 회사가 지울 수 없어요.
  • 구글 계정의 '저장된 게임' 사본: 구글 계정 안에 있어요. 구글 플레이 게임즈 앱(또는 구글 계정 설정)에서 이 게임의 데이터를 지울 수 있어요.
  • 삭제한 계정은 되살릴 수 없어요. 산 상품은 사라지며 환불되지 않아요(환불은 구글 플레이 환불 규정을 따라요).
